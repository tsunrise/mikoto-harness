# Mikoto Harness: An opinionated agent setup for Pi

This repo includes a bunch of extensions and skills for [Pi Coding agent](https://pi.dev/), serving as building blocks for my personal agent system, *Mikoto*.

## Extension Interoperability

- Some extensions in the repo require one or more extension in the repo to be loaded first.
- No extension in the repo require any extension outside this repo.
- Every extension in the repo guarantees no conflict with all other extensions in the repo.
- No extension guarantees no conflict with any other extensions outside this repo.
